# 待办：项目关键记忆与渐进遗忘

状态：已登记，尚未实现。此项排入后续工作；不改变正在进行的任务与技能晋升修复。

## 需求

- 从项目或任务的重要内容中提炼关键记忆，用关键词建立索引，供有权限的 Bot 搜索、定位并读取对应内容。
- 记忆越久远，可用于召回的关键词越少，逐步减少可找到的线索，最终达到无法通过记忆机制召回的状态。
- 保存的关键词应概括项目关键点，而不只是随机编号或自动拼接的标题；应能让 Bot 在实际任务中使用。

## 现有基础

现有任务流会为派发、结果、验收、心得等节点建立群内隐藏关键词，并提供搜索与打开工具；任务明细归档后也可通过归档索引查找。这些索引目前没有按时间递减的遗忘规则。实施前需完整核对当前及归档两条检索路径、历史数据回填和群权限。

## 待设计与实现

- [ ] 明确项目记忆的范围和关键内容的产生时机，接入现有真实任务节点；验证生成的关键词可用于实际查找。
- [ ] 设计可持久化的记忆年龄、关键词递减阶段和最终遗忘规则，覆盖旧记录、重启以及时间边界。不能用随机性掩盖规则或把固定不变的摘要当作永久检索入口。
- [ ] 在搜索及精确关键词打开时一致执行遗忘规则，避免通过现有或归档索引绕过；保持群隔离和现有权限。
- [ ] 区分供 Bot 召回的记忆索引与正式任务账本、审核证据和用户数据；在明确数据保留策略前，不删除或改写正式记录。
- [ ] 设计重复访问、重新提及和重要记忆是否会刷新或增强记忆，防止未经确认擅自改变遗忘语义。
- [ ] 通过隔离数据验证新记忆、分阶段减少、最终无法召回、重启、历史记录、群隔离及原任务账本可用性；完成独立审查、构建和实际运行验收。

## 待确定

- 关键词递减和最终遗忘的具体时间尺度、各阶段保留数量，以及是否允许按项目或重要性调整。
- Bot 再次检索、打开或在新任务中重新使用一条记忆时，是否刷新其年龄或重新形成记忆。
- “想不起来”是否仅表示 Bot 的记忆工具不再召回，还是还要影响用户查看原始任务历史；两者涉及不同的数据保留与权限后果，实施前需明确。
