# 五分钟任务催办 Implementation Plan

**Goal:** 所有现有群及未来新群每五分钟检查未完成正式计划，提醒当前主理核对并催办执行者；计划完成后停止提醒。

**Architecture:** 复用 taskflow.js 已有五分钟 Host 定时扫描，不增加外部 Hermes cron。通过 recovery.js 的正式任务事件和保留/接纳事务唤醒当前主理；events 账本持久化上次投递时间，避免重复定时器及重启刷屏。

**Tech Stack:** DS Bot Host JavaScript、现有 SQLite Scheduler/events、原生 group_relay/Session。

## 当前规则：执行空档才提醒

- 每五分钟检查启用且仍有开放计划的群。只要同群有执行者对未提交的正式卡处于实时执行回合，跳过该群的周期提醒。其他群和私聊不参与判断。
- 执行者空闲时，原生提醒卡送给当前主理。发出及接纳时复查执行情况。账本仍标为 running 但没有实时执行回合时，可以提醒。
- `v0.4.0` 包含群评审派工纠正与执行空档提醒。该版本的候选包通过 19 项联合回归，安装后读回校验了 265 个发布文件。真实群触发单独验收。

边界：程序运行期间定时检查；已 completed/cancelled/cancelling 的计划不催办。不自动取消或重派，不绕过审批，不让执行者产生普通群内汇报。已提交结果仍需主理验收；全卡 verified 但计划 open 时提醒主理 finish。发送结果不明时本周期不重复，下个五分钟周期仍可提醒尚未完成的计划。
