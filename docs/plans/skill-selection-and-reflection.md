# 任务阶段主动选技能与可选错误心得 Implementation Plan

**目标：** Bot 根据任务及阶段主动发现、选择并读取适用技能；无实际错误时心得不要求错误段。

**架构：** 延续宿主的技能注册表、当前会话权限和技能准备工具；在实际任务开始及阶段变化时要求重新判断，明确适用时机与已读取正文，保持可选无适用技能分支，不发额外计费模型请求。心得校验支持原有四段与省略错误段的三段，并统一执行者及主理提示；不猜测任务是否出错。

**边界：** 不改变群与私有技能授权、技能晋升门槛、生产心得内容；发布以运行包为基线，不覆盖暂停的其他修改。

1. [ ] 分析现有任务阶段和技能注册/读取、运行安装及模型回合边界，列出精确触发条件。
2. [ ] 先写红测：三段心得和四段心得均可提交及汇总；错误段出现时须非空且顺序正确；其他必需段仍必填；旧记录可读。
3. [ ] 修改心得格式校验、工具说明和 taskflow 指引并验证真实工具调用及原数据不受影响。
4. [ ] 按真实生命周期写红测：任务开始/阶段变化重新判断并实际读取合规技能；无适用、共享/私有边界、失败、状态变化及重复执行路径。
5. [ ] 实现最小闭环，不使用额外模型请求；跑定向回归和完整源码门禁。
6. [ ] 独立审查，基于当前安装版制作精确候选、核对运行包闭包，构建、验证和交付；真实 Bot 的自主判断及加载记录单独验收。
