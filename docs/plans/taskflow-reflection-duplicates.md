# 同计划心得查重实施计划

**目标** 每次执行者提交心得时检查同一计划的已保存真实心得。先保存的心得保留，后提交的重复稿退回给原提交者重写。无实际错误时省略错误段。

**实现** 在 Scheduler 保存心得的事务内比对排除标题、标点和空白后的正文。拦截相同正文及高相似正文，提示重复卡与改写依据。忽略自动占位，按计划限定范围。沿用工具错误回执，保留主理汇总和原始出处。

**项目级触发** 阶段计划完成后继续推进项目。关联计划的心得登记和汇总由 `group_goal complete` 解锁，总验收后向缺心得的原执行者发送原生任务通知。独立计划及定时任务也须等整份计划验收收尾后才开放心得。提交结果、返工和单卡验收期间，心得入口统一返回延后状态。新计划保存关联目标 ID，旧计划用同群目标的创建和结束时间判定归属。总验收时把解锁状态写入计划账本，群目标移出历史窗口后仍可补写。已保存的历史心得保留。

**验证与发布** 重复退回、原稿保留、同结论不同证据、自动占位替换及三段/四段格式通过回归。查重查询按计划 ID 限定，排除自动占位。源码全量测试通过 2326 项，跳过 3 项。`v0.4.2` 以当前共享技能库版为基线，安装后校验 266 个发布文件，桌面窗口响应正常并读到团队界面。真实群组中 Bot 收到退回后自主重写仍待观察。

**项目级验证** `v0.4.3` 候选包已通过阶段收尾拦截、总验收后原生通知及历史目标移出列表后补写的回归。最终版 `hermes verify --json` 的构建、全量测试、Lint 和客户端一致性检查均以退出码 0 完成。先前两轮因集成测试等待模拟回合结束而超时，已改为验证原生通知、心得入账和回执。候选包安装预检通过，266 个发布文件与归档清单一致。候选专项 5 项通过，包含关闭群任务流时总验收仍持久解锁、且不发送通知的回归。桌面已安装 `v0.4.3`，安装文件哈希与 266 项清单逐一相符。重启后读到团队界面，生产账本已加载项目关联和心得解锁字段。更新前一张执行中的卡重启后变为 `unknown`，交付状态待核验。真实群组的项目总验收与心得提交流程待现场观察。
